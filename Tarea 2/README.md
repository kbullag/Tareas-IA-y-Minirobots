# Autómatas Celulares - Ejercicios y Problemas

Repositorio con la solución de los ejercicios de la sección **Ejercicios y Problemas** de Autómatas Celulares.

## Estructura

- `Ejercicio_1/`: análisis escrito de reglas básicas de comportamiento.
- `Ejercicio_2/`: autómata celular probabilístico para la difusión de un incendio forestal.
- `Ejercicio_3/`: simulación de un robot con tres sensores de distancia.
- `Ejercicio_4/`: diagramas de Voronoi para diferentes servicios de una ciudad.

Cada ejercicio contiene su propio `README.md` y `requirements.txt`.

## Ejecución

Los ejercicios 2, 3 y 4 pueden ejecutarse mediante Jupyter Notebook, JupyterLab o Google Colab.
