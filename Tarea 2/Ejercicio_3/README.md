# Ejercicio 3 - Robot con tres sensores

Simulación de un robot que recorre un espacio bidimensional con cuatro obstáculos distribuidos aleatoriamente y utiliza tres sensores de distancia para evitar colisiones.

## Contenido
- `Ejercicio_3_Robot.ipynb`: notebook con la simulación, reglas de movimiento y trayectoria.

## Ejecución
Abrir el notebook en Jupyter Notebook, JupyterLab o Google Colab y ejecutar las celdas en orden.
