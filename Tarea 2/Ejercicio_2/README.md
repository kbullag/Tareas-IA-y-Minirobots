# Ejercicio 2 - Autómata celular probabilístico: incendio forestal

Modelo de difusión de un incendio forestal mediante un autómata celular probabilístico.

## Contenido
- `Ejercicio_2_Incendio_Forestal.ipynb`: notebook con la simulación y visualizaciones.

## Ejecución
Abrir el notebook en Jupyter Notebook, JupyterLab o Google Colab y ejecutar las celdas en orden.

## Modelo
La simulación utiliza una cuadrícula bidimensional y vecindad de Moore. Los estados representan espacio vacío, árbol, fuego y zona quemada.
