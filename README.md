# Tareas-IA-y-Minirobots

Cada ejercicio vive en su propia carpeta, con su propio código, README y
`requirements.txt`, como si fuera un mini-proyecto independiente dentro
del repositorio.

- [`ejercicio4_ag_imagen/`](./ejercicio4_ag_imagen) — Algoritmo genético
  que evoluciona una población de matrices RGB hacia una imagen objetivo.
- [`ejercicio5_ag_palabra/`](./ejercicio5_ag_palabra) — Algoritmo genético
  que evoluciona una población de palabras hacia una palabra objetivo, y
  la reproduce por voz.

Entra a cada carpeta y sigue el README correspondiente para instalar
dependencias y ejecutar el script.
